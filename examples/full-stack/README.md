# Full-Stack Example

## Stack
- **Backend:** Python / FastAPI
- **Frontend:** Vue 3 / TypeScript
- **Database:** PostgreSQL
- **APIs:** REST

## Structure
```
backend/
├── app/
│   ├── api/
│   ├── models/
│   ├── services/
│   └── tests/
frontend/
├── src/
│   ├── components/
│   ├── views/
│   ├── stores/
│   └── services/
database/
└── migrations/
```

## Try It
> "Add a customer approval workflow to invoices, with a migration and API contract update."

## Workflow
Use the `feature-development`, `api-change`, and `database-change` workflows together.

## Model Usage
- Local: analysis, summaries, review.
- Cloud: planning and complex implementation.
