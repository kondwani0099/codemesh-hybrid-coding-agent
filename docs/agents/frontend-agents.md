# Frontend Agents

## Vue Agent
Specialist for Vue 2/3, Composition API, Pinia, Vue Router, and frontend API integration. See `.github/agents/frontend/vue.agent.md` and `.github/skills/frontend/vue/SKILL.md`.

## React Agent
Specialist for React, hooks, state management, routing, and component architecture. See `.github/agents/frontend/react.agent.md` and `.github/skills/frontend/react/SKILL.md`.

## Frontend Reviewer
Reviews UX, architecture, performance, accessibility, state management, and API integration. See `.github/agents/frontend/frontend-reviewer.agent.md`.

## Common Principles
- Use existing component patterns.
- Reuse components.
- Handle loading/error states.
- Preserve responsive design and accessibility.
