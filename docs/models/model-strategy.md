# Model Strategy

## The Optimization
> **Use local models to understand the codebase and prepare intelligence; use expensive models only when superior reasoning or implementation capability is required.**

## When to Use Local
- File summaries.
- Repository indexing.
- Code explanations.
- Context compression.
- Simple review.
- Small fixes.

## When to Use Cloud
- Architecture decisions.
- Complex implementation.
- Complex debugging.
- Large refactors.
- Security-sensitive reasoning.
